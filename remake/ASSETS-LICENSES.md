# Asset licences

Mini Militia by Kadiyafali is a private, personal-use project and is never published.

## Original game assets (Appsomniacs)

Imported unchanged by `tools/import-original-assets.sh` from `source/apk-project/assets`
(copyright of the original developers; used privately, never redistributed):

| Assets | Files |
|---|---|
| Maps, tilesets | `Content/{sd,hd,hdr}/*.tmx`, `*.tsx`, `tile64*_new.png` |
| Sprite atlases, backgrounds, UI images | `Content/{sd,hd,hdr}/*.plist`, `*.png` |
| Particle effects | `Content/files/*.plist` (textures in `Content/{sd,hd,hdr}`) |
| Fonts as shipped in the original APK | `Content/fonts/GROBOLD.ttf`, `digitalix.ttf`, `Marker Felt.ttf`, `arial.ttf` |
| Menu music | `Content/music/presMix.mp3` |
| Launcher icon | `proj.android/app/res/mipmap-*/ic_launcher.png` |

The original sound bank (`da2sound16.ckb`) is **not** used.
